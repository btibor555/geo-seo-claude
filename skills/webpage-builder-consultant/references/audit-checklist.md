# Conversion Audit Checklist & Scoring Rubric

Score each item: **2** = strong, **1** = partial, **0** = missing/broken. Tag evidence
**[Certain]** (seen), **[Likely]** (inferred), **[Guessing]** (needs owner).
Pillar score = earned ÷ max × pillar weight. Sum = Conversion Readiness Score (0–100).

## 1. Clarify — weight 20

| # | Check | Pass looks like |
|---|-------|-----------------|
| C1 | 5-second test: what they do, for whom | H1 names service + audience/outcome |
| C2 | Location / service area visible above fold | City/region in headline or sub |
| C3 | Money service is prominent | Most profitable service first, own page |
| C4 | Plain language, no jargon | Customer words, not industry words |
| C5 | One primary action is obvious | Single dominant CTA, not 12 options |
| C6 | Page not cluttered | Clear hierarchy, whitespace, no sliders |

## 2. Build Trust — weight 20

| # | Check | Pass looks like |
|---|-------|-----------------|
| T1 | Reviews/rating visible near CTA | Stars + count + source (Google) |
| T2 | Real testimonials with names/context | Not generic, not invented |
| T3 | Proof of work | Before/after, project photos, case results |
| T4 | Credentials | Licenses, board certs, bar admission, insurance, BBB, manufacturer certs |
| T5 | Real people | Team/owner photo, not stock |
| T6 | Clear contact info & NAP | Phone, address/service area, hours |
| T7 | Design credible & current | Modern, consistent, no broken elements, current © year |
| T8 | Risk reducers | Guarantee, warranty, financing, price ranges, "no obligation" |

## 3. Capture — weight 25

| # | Check | Pass looks like |
|---|-------|-----------------|
| K1 | Specific CTA copy | "Request a Free Inspection" vs "Learn More" |
| K2 | CTA above fold + repeated | Hero + after each major section |
| K3 | Phone is click-to-call (`tel:`) | Tappable, in header on mobile |
| K4 | Form or booking exists and is easy to find | On page, not buried in /contact |
| K5 | Form friction is low | 3–5 fields; optional fields marked |
| K6 | Booking link / online scheduling | Where the business can take bookings |
| K7 | Secondary capture | Chat, text-us, callback request, lead magnet |
| K8 | Thank-you page sets expectations | Confirms, gives timeline, next step |

## 4. Follow Up — weight 20 (mostly "needs owner confirmation")

| # | Check | Pass looks like |
|---|-------|-----------------|
| F1 | Submissions reach a CRM / tracked place | Not only an inbox |
| F2 | Owner/team alert instantly | SMS/push, not just email |
| F3 | Lead gets confirmation | Auto SMS/email |
| F4 | Speed-to-lead ≤ 5 min in business hours | Measured |
| F5 | Nurture/reminder sequence | Unbooked leads get 3–5 touches |
| F6 | Missed-call text-back | For call-driven businesses |
| F7 | Lead source tagged | UTM / call tracking / form source |

## 5. Mobile & Speed — weight 10

| # | Check |
|---|-------|
| M1 | Viewport meta, responsive layout, no horizontal scroll |
| M2 | Sticky call/book button on mobile |
| M3 | Form usable on phone (input types, big tap targets) |
| M4 | Load weight reasonable (images compressed, no giant sliders/video autoplay) |
| M5 | No intrusive pop-up on entry |

## 6. Funnel Integrity — weight 5 (score N/A → redistribute if no funnel)

| # | Check |
|---|-------|
| N1 | Ad/source promise matches landing headline (message match) |
| N2 | Paid traffic goes to a focused page, not the homepage |
| N3 | No dead ends; every step has one next action |
| N4 | Conversion tracking fires on the real conversion (submit/booking/call), not pageview |

## Common diagnoses (pick the biggest)

- Offer is unclear · Page doesn't build trust · CTA is weak · Form is hard to find ·
  Phone is buried · Mobile is broken · No booking link · Basic questions unanswered ·
  No obvious next step · Leads submit but nobody follows up · Ads send traffic to the homepage.

## When NOT to lead with a website

| Situation | Redirect to |
|-----------|-------------|
| No traffic | GBP, reviews, local SEO, ads, outreach |
| Strong site already (score ≥ 85) | Follow-up, CRM, reviews, call handling |
| Owner only cares about design taste | Re-anchor on main action + numbers, or walk |
| No clear offer | Offer clarification session first |
| No follow-up process | Build follow-up first |
| Heavy compliance (HIPAA intake, payments) | Specialist platform + review |
| Needs custom software | Scoped app build, not a website |

## Launch QA (test like a customer)

- [ ] Every button and link works (desktop + mobile)
- [ ] Submit every form yourself → CRM entry created, lead source tagged
- [ ] Owner alert arrives (SMS/email) · lead confirmation arrives
- [ ] Call the phone number from the page · missed-call text-back fires
- [ ] Booking link books a real slot and sends reminders
- [ ] Thank-you page loads; conversion event fires in analytics
- [ ] Mobile layout on iOS + Android, sticky CTA visible
- [ ] Page speed acceptable; images compressed
- [ ] Privacy policy, disclaimers, license numbers present
- [ ] Accounts (domain, hosting, CRM, forms) owned by client
